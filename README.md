# ResumeHippocrates

Automated resume builder powered by AI and optimized for ATS (Applicant Tracking Systems). Instantly generate and enhance resumes with industry keywords, rich text editing, and downloadable PDF support.

🌐 [Live Demo](https://resume-hippocrates.onrender.com/)
📦 Full-stack: React, Node.js, MongoDB, OpenAI API
🖼️ Profile image upload & enhancement (ImageKit integration)
⚡ Deploy frontend & backend together on Render.com

## Features
- Authenticated user dashboard for resume management  
- AI-enhanced content using OpenAI GPT  
- ATS keyword optimization and PDF export  
- Secure REST API and cloud-based image upload  
- Mobile-responsive UI with color/theme customization

## Getting Started

Clone the repo:
```

git clone https://github.com/trnahnh/Resume-Hippocrates.git
cd Resume-Hippocrates

```

### Frontend setup (`client`)
```

cd client
npm install
npm run start

```

### Backend setup (`server`)
```

cd server
npm install
npm start

```

Configure `.env` files in both `client/` and `server/` as needed.
